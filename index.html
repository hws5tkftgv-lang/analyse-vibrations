ℹ️ Informations

Objectif

Cette application sert à comprendre comment une machine vibre et pourquoi certaines vibrations indiquent un défaut.

2️⃣ Unités

RPM = tours/minute. Hz = tours/seconde.

Hz = RPM ÷ 60

3️⃣ Le 1× (le plus important)

1× correspond à la vitesse de rotation.

Exemple : 1500 RPM → 1500 ÷ 60 = 25 Hz → donc 1× = 25 Hz.

4️⃣ Amplitude (combien ça vibre)

On regarde la hauteur des lignes dans le spectre. L’unité ici est mm/s.

Plus le chiffre est grand → plus c’est sérieux.

5️⃣ Zones ISO (gravité)

Indice pédagogique inspiré ISO

Ce simulateur utilise des seuils inspirés de l’ISO 10816 / 20816 – Classe I pour apprendre à interpréter les zones A-B-C-D.

Classe I :
  • Petites machines
  • Moteurs électriques
  • Puissance typiquement < 15 kW
  • Machines rigides, montées sur socle
Classe II (non utilisée ici) :
  • Machines plus grosses
  • Structures plus flexibles
  • Seuils ISO plus permissifs
Important : les valeurs affichées restent pédagogiques. Elles ne remplacent pas une vraie mesure RMS prise avec un analyseur de vibration.

Les zones ISO servent à savoir si la vibration est acceptable :

A = très bon • B = acceptable • C = problème • D = critique

Zone ISO Couleur Amplitude RMS (mm/s) Interprétation
A Vert ≤ 0,71 État excellent (machine neuve ou équilibrée)
B Bleu 0,71 – 1,8 Acceptable en service continu
C Orange 1,8 – 4,5 Défaut présent – intervention à planifier
D Rouge > 4,5 Critique – arrêt recommandé

6️⃣ Courroie

La courroie a sa propre fréquence. Elle peut créer des pics différents du moteur.

7️⃣ Formules utilisées (simplifiées)

Vitesse de courroie :

Vitesse = π × diamètre × RPM

Fréquence courroie :

Hz courroie = vitesse ÷ longueur

8️⃣ Défauts (exemples)

Balourd : pic fort à 1×

Désalignement : pic fort à 2×

Jeu mécanique : plusieurs harmoniques

Méthode de lecture

1) Trouver 1× • 2) Voir harmoniques • 3) Lire amplitude • 4) Vérifier ISO • 5) Associer un défaut

9️⃣ Calcul de la longueur de la courroie

Pour une transmission à courroie ouverte (comme dans ce simulateur), on utilise une formule qui permet d’estimer la longueur de la courroie.

Formule utilisée :

Longueur ≈ 2 × C + (π / 2) × (D1 + D2) + ((D2 − D1)² / (4 × C))

Signification des termes :

  • C : distance centre-à-centre entre les deux poulies
  • D1 : diamètre de la poulie menante
  • D2 : diamètre de la poulie menée
  • π (pi) ≈ 3,14

Cette formule additionne :

  • les parties droites de la courroie
  • les parties enroulées sur les poulies
  • une correction si les diamètres sont différents

Important : la longueur obtenue est théorique. En pratique, on choisit toujours une courroie standard la plus proche.

1️⃣0️⃣ Influence de l’angle de la courroie

La courroie n’enveloppe pas complètement les poulies.

La portion de poulie réellement touchée s’appelle :

l’angle d’enroulement

Pourquoi c’est important ?

  • Grand angle → meilleure adhérence
  • Petit angle → plus de risque de glissement

Exemples :

  • Poulies très rapprochées → angle faible → glissement possible
  • Poulies éloignées → angle plus grand → transmission plus stable

Dans ce simulateur :

  • l’angle est calculé automatiquement
  • il influence la trajectoire de la courroie
  • il peut influencer les défauts simulés

1️⃣1️⃣ Longueur réelle vs longueur calculée

La formule suppose que la courroie roule sur le diamètre extérieur des poulies.

En réalité :

  • la courroie s’enfonce légèrement dans la gorge
  • le diamètre réel de contact est un peu plus petit

Conséquences :

  • la longueur réelle est légèrement différente
  • la vitesse réelle peut varier un peu

En analyse vibratoire, ces écarts sont :

  • normaux
  • acceptés
  • pris en compte avec des tolérances

⚡ 1️⃣2️⃣ Influence de la fréquence électrique (Hydro-Québec)

Au Québec, la fréquence électrique est :

60 Hz

Cette fréquence peut apparaître dans un spectre de vibration sans être un défaut mécanique.

On peut voir :

  • 60 Hz
  • 120 Hz (2 × 60)
  • 180 Hz (3 × 60)

Sources possibles :

  • champ magnétique du moteur
  • effets électromagnétiques
  • couplage moteur / structure

⚠️ Erreur fréquente! :

Un pic à 60 Hz n’est PAS automatiquement un défaut mécanique.

Règle simple :

Si un pic est exactement à 60 Hz ou un multiple, penser d’abord à l’électricité.

1️⃣3️⃣ Ce que fait ce simulateur

Ce simulateur sert à :

  • comprendre les relations entre vitesses
  • visualiser les pics typiques
  • apprendre à lire un spectre vibratoire

Il ne remplace pas :

  • un vrai capteur
  • une vraie machine
  • une vraie analyse terrain

Mais il est parfait pour apprendre sans risque.

Pruftechnik — Terminologie utilisée

Le simulateur utilise volontairement les mêmes termes que les analyseurs vibratoires Pruftechnik afin de préparer l’élève au terrain.

1️⃣ RMS (Root Mean Square)

Valeur efficace de la vibration.

  • Représente l’énergie réelle de vibration
  • C’est la valeur utilisée pour la norme ISO

Dans Pruftechnik : affiché comme Velocity RMS (mm/s)

2️⃣ Velocity (Vitesse vibratoire)

Indique la vitesse de déplacement de la machine pendant la vibration.

  • Unité : mm/s
  • Très sensible aux défauts mécaniques globaux

Dans Pruftechnik : mode Velocity

3️⃣ Peak (Pic)

Valeur maximale instantanée d’un signal.

  • Plus sensible aux chocs
  • Moins stable pour l’évaluation ISO

Différence importante :

  • ISO = RMS
  • Chocs / impacts = Peak

4️⃣ 1×, 2×, 3× (Ordres)

Les ordres correspondent à des multiples de la vitesse de rotation.

  • 1× = vitesse de rotation
  • 2× = deux fois la vitesse
  • 3× = trois fois la vitesse

Dans Pruftechnik : affiché sous forme de pics ordonnés

5️⃣ Spectrum (Spectre)

Graphique qui montre les vibrations par fréquence.

  • Axe horizontal = Hz
  • Axe vertical = amplitude (mm/s)

Dans Pruftechnik : écran principal d’analyse

6️⃣ Time Waveform (Signal temporel)

Représentation de la vibration dans le temps.

  • Permet de voir les chocs
  • Très utile pour les roulements

Non simulé ici, mais important à connaître

7️⃣ FFT (Fast Fourier Transform)

Transformation mathématique qui convertit :

Temps → Fréquence

Sans FFT, il serait impossible d’identifier les défauts.

Pruftechnik : FFT automatique en arrière-plan

8️⃣ ISO 10816 / 20816

Norme internationale pour juger la gravité vibratoire.

  • Basée sur la vitesse RMS
  • Classes A à D

Utilisée directement dans Pruftechnik

9️⃣ Alarmes (Alert / Danger)

Seuils configurables pour avertir l’utilisateur.

  • Alert = intervention à planifier
  • Danger = arrêt recommandé

Simulé ici via les zones ISO

🔟 Trending (Suivi dans le temps)

Comparaison des mesures sur plusieurs jours ou semaines.

  • Permet de voir une dégradation
  • Fondamental en maintenance prédictive

Non simulé ici, mais concept clé à comprendre
